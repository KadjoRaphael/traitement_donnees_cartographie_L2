---

## 🎯 Objectif du cours

L'objectif de ce cours est d'apprendre à **analyser des données géographiques**
et à les **représenter sous forme de graphiques et de cartes**.

Au cours du semestre, nous suivrons progressivement les différentes étapes qui
permettent de passer d'un jeu de données à une carte thématique :

**Données → préparation → analyse statistique → sémiologie graphique
→ discrétisation → cartographie → analyse et commentaire**

L'objectif n'est donc pas seulement d'apprendre à utiliser des logiciels.

Il s'agit également de comprendre :

- ce que représentent les données ;
- comment vérifier leur qualité ;
- comment les organiser et les traiter ;
- quels calculs statistiques utiliser ;
- comment choisir une représentation cartographique adaptée ;
- comment construire une carte lisible ;
- comment interpréter et commenter une carte.

À la fin du cours, vous devrez être capable de produire une **carte thématique
à partir d'un jeu de données**, puis de l'analyser et de la commenter.

## Séance 1 - De la donnée à la carte

Cette première séance présente la logique générale du cours.

Vous apprendrez notamment à distinguer :

- une donnée ;
- une information ;
- une variable statistique ;
- un individu statistique ;
- une variable qualitative ;
- une variable quantitative ;
- un fond de carte.

Nous verrons également les différentes étapes permettant de passer
de l'observation d'un phénomène géographique à sa représentation
sur une carte.

👉 [Accéder à la séance 1](01_Seance1_Introduction.md)

## Séance 2 - Sources et types de données géographiques

Avant d'analyser une donnée, il faut comprendre **ce qu'elle représente**.

Cette séance permet notamment de distinguer :

- les données qualitatives nominales ;
- les données qualitatives ordinales ;
- les données quantitatives discrètes ;
- les données quantitatives continues ;
- les valeurs absolues ;
- les valeurs relatives.

Nous verrons également comment rechercher des données géographiques
et comment vérifier leur source, leur date, leur définition et leur
échelle géographique.

👉 [Accéder à la séance 2](02_Seance2_Sources_Donnees.md)

---

## Séance 3 - Statistique descriptive univariée

Une fois les données identifiées, il faut apprendre à les **décrire et
à les résumer**.

Cette séance introduit les principaux indicateurs de statistique descriptive :

- effectif ;
- fréquence ;
- minimum et maximum ;
- moyenne ;
- médiane ;
- mode ;
- étendue ;
- variance ;
- écart-type ;
- coefficient de variation.

Les calculs seront notamment réalisés sous **Excel** ou
**LibreOffice Calc**.

L'objectif est surtout d'apprendre à **interpréter les résultats** afin
de mieux comprendre la distribution des données avant de les cartographier.

👉 [Accéder à la séance 3](03_Seance3_Statistique_Descriptive.md)

---

## Séance 4 - Structurer et nettoyer une base de données géographique

Des données mal organisées peuvent produire des erreurs lors de l'analyse
ou de la cartographie.

Cette séance est donc consacrée à la préparation d'une base de données
sous Excel.

Nous travaillerons notamment sur :

- la structure d'un tableau ;
- les valeurs manquantes ;
- les doublons ;
- les formats des données ;
- les unités ;
- les identifiants géographiques ;
- les codes géographiques ;
- les clés de jointure ;
- la préparation d'un fichier CSV.

Une règle importante sera utilisée :

**Une ligne = un individu statistique**  
**Une colonne = une variable**

L'objectif est d'obtenir un fichier propre et structuré pouvant ensuite
être utilisé dans **Magrit**.

👉 [Accéder à la séance 4](04_Seance4_Nettoyage_Donnees.md)

## Séance 5 - Sémiologie graphique

Une carte ne consiste pas simplement à placer des données sur un fond
de carte.

Il faut choisir une représentation graphique adaptée à la nature
de l'information.

Cette séance présente notamment :

- les éléments essentiels d'une carte ;
- les variables visuelles ;
- la taille ;
- la valeur ;
- la couleur ou teinte ;
- la forme ;
- l'orientation ;
- le grain ;
- la texture ;
- les propriétés perceptives des variables visuelles.

Nous apprendrons notamment à choisir une représentation selon la
nature de la donnée :

**Catégories → teinte ou forme**  
**Ordre / valeurs relatives → valeur (clair → foncé)**  
**Quantités absolues → taille**

👉 [Accéder à la séance 5](05_Seance5_Semiologie_Graphique.md)

## Séance 6 - Discrétisation des données quantitatives

Pour réaliser certaines cartes thématiques, notamment les cartes
choroplèthes, il est nécessaire de regrouper les valeurs en classes.

Cette opération est appelée **discrétisation**.

Cette séance permettra de comprendre :

- pourquoi regrouper des valeurs en classes ;
- comment déterminer les limites des classes ;
- les principales méthodes de discrétisation ;
- l'influence du choix des classes sur la lecture d'une carte.

L'objectif est de comprendre qu'une même série de données peut produire
des représentations différentes selon la méthode de discrétisation choisie.

👉 [Accéder à la séance 6](06_Seance6_Discretisation.md)

Les notions étudiées lors des séances précédentes seront mobilisées

👉 [Accéder à la séance 7](07_Seance7_Cartographie_Magrit.md)

## Séance 8 - Commenter une carte et préparer le dossier final

Produire une carte ne constitue pas la dernière étape du travail.

Il faut également être capable de :

- lire la carte ;
- identifier les principales structures spatiales ;
- décrire les contrastes entre les territoires ;
- interpréter les résultats ;
- prendre du recul sur les données et les choix cartographiques ;
- présenter correctement son travail.

Cette dernière séance permet également de préparer le
**dossier cartographique final**.

# 💡 Quelques conseils pour réussir

Ce cours repose sur une progression.

Il est important de ne pas apprendre uniquement les manipulations
techniques dans Excel ou Magrit.

Essayez toujours de comprendre :

1. **Quelle donnée est utilisée ?**
2. **Que mesure-t-elle ?**
3. **Quelle est son unité ?**
4. **Quelle est sa source et sa date ?**
5. **S'agit-il d'une valeur absolue ou relative ?**
6. **Comment les valeurs sont-elles distribuées ?**
7. **Quelle représentation cartographique est adaptée ?**
8. **Que montre finalement la carte ?**

Une carte est une **construction** : le choix des données, des traitements
statistiques, des classes, des couleurs et des symboles influence la
manière dont un phénomène géographique est représenté et interprété.
