# Traitement des données et cartographie

**L2 Géographie et aménagement — Université Paris 8**

Bienvenue sur le site pédagogique du cours **Traitement des données et cartographie**.

Ce site regroupe :

- les supports de cours ;
- les activités pratiques (TD) ;
- les données nécessaires aux exercices ;
- les ressources complémentaires.

## 🚀 Par où commencer ?

Commencez par la page **Introduction** pour découvrir les objectifs du cours,
le programme, les modalités d'évaluation et les outils utilisés.

👉 [**Commencer le cours — Introduction**](00_Introduction.html)

## 🧭 Fil conducteur du cours

Tout au long du semestre, nous suivrons progressivement la chaîne suivante :

**données → préparation sous Excel → analyse statistique → sémiologie graphique
→ discrétisation → cartographie avec Magrit → analyse et commentaire**

Chaque séance correspond à une étape de cette progression.
